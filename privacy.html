Política de privacidade — AgentTube

Atualizada em 2 de outubro de 2026.

O AgentTube é usado exclusivamente pelo seu autor, Dr. André Gustavo Gumz Eichstaedt, para enviar vídeos ao seu próprio canal do YouTube.

Dados acessados

O app usa a API de Dados do YouTube, com autorização OAuth do autor, apenas para enviar vídeos e definir miniaturas no canal do autor. Nenhum dado de outros usuários é coletado, armazenado, vendido ou compartilhado.

Armazenamento

O token de acesso fica guardado de forma privada no computador do autor e em segredos criptografados do GitHub Actions. Pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
